Blob Tracking in TouchDesigner

A ready-to-run TouchDesigner project that detects and tracks blobs in video in real time. Each tracked point gets a square marker and its pixel coordinates, and the points are connected by thin lines. It is the "tracking HUD" look from music videos, reels and installations.

Open one .toe file, swap in your own footage, and the effect runs. No code, no plugins, nothing beyond TouchDesigner.

Quick start

  1. Install TouchDesigner 2022.32600 or newer (the free non-commercial edition should work).
  2. Get the project: git clone https://github.com/DevxD98/Blobtracking.git, or download the .toe from the latest release.
  3. Open blob-tracking.3.toe in TouchDesigner.
  4. Delete the sample video node and drop in your own footage. The README shows which node.

How it works

Video comes in, blobs are detected, their positions are tracked frame by frame, markers, labels and lines are drawn, and the result is composited over the source video. The project is a TouchDesigner node network: TOPs (texture operators) handle the image processing and CHOPs (channel operators) carry the position data.

FAQ

What is blob tracking?

Blob tracking is a computer-vision technique that finds connected regions of similar pixels (blobs) in an image and follows them from frame to frame, giving a position for each blob over time. You can draw those positions on screen or use them to drive other visuals.

Do I need a webcam or special hardware?

No. The project works on a normal video file. A webcam or other video source is optional.

Do I need to buy TouchDesigner?

Probably not. TouchDesigner has a free non-commercial edition, which should be enough to run this project. Check Derivative's licence terms for commercial use.

Which TouchDesigner version do I need?

2022.32600 or newer, as tested by the author. Newer builds should open it.

Is this a Python or OpenCV project?

No. It is a native TouchDesigner .toe project built from TOPs and CHOPs. There is no separate code to install or run.
